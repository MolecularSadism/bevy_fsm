# bevy_fsm_macros

Procedural macros for [bevy_fsm](https://crates.io/crates/bevy_fsm) - an observer-driven finite state machine framework for Bevy ECS.

This crate provides the `#[derive(FSMState)]` and `#[derive(FSMTransition)]`
derive macros. **You don't need to depend on it directly** - it is re-exported
by `bevy_fsm`, which is released in lockstep with this crate.

For usage, examples, compatibility, and documentation, see the main crate:

- Crate: <https://crates.io/crates/bevy_fsm>
- Docs: <https://docs.rs/bevy_fsm>
